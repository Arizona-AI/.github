## 🛠 Ключевые проекты экосистемы

### 1. **ArizonaAI (Нейросетевой ассистент)**
Виртуальный помощник, спроектированный для анализа игровых ситуаций, поиска правил, ответов на вопросы и автоматизации рутинных текстов. Включает специализированные модели.

### 2. **Arizona Forum Styler**
Браузерное расширение для кастомизации интерфейса `forum.arizona-rp.com`.
* Более 80 предустановленных тем оформления.
* Детальный визуальный редактор цветов, шрифтов (Google Fonts) и кастомизации фона (изображения или видео).
* Эффект матового стекла (Glassmorphism) с регулировкой прозрачности и силы размытия.

### 3. **Arizona LogsParser Helper**
Аналитическое расширение для работы в веб-панели логов `arizonarp.logsparser.info`.
* **GeoIP-анализ** — автоматическое определение местоположения, провайдера и типа соединения (прокси, VPN, хостинг, мобильная сеть).
* **Калькулятор расстояний** — расчет дистанции между IP-адресом регистрации и точкой последнего входа по формуле гаверсинуса.
* **Интерфейс** — фиксация навбара и шапки таблиц логов, скрытие бокового меню, поддержка тем оформления.
* **Удобство** — быстрое копирование строк, меток времени и IP-адресов в один клик.

### 4. **WatchKeeper**
Инструмент для мониторинга событий, безопасности и оперативного контроля за действиями на Discord серверах Arizona RP.
